My HTML Tools Dashboard

Your central dashboard for launching and organising the browser-based tools in this repository.

Find a tool

  • Use the search box to filter tools by name, description, category or status.
  • Choose a category chip such as Work, PTTG, Data or Personal to narrow the list.

Organise your tools

  • Click the star on a card to add or remove it from Favorites. Favorites are saved in this browser.
  • Recently Used shows the last five tools you opened on this browser.

Personalise the dashboard

  • Use the moon/sun button in the top-right corner to switch between dark and light themes. Your theme choice is remembered.
  • Select Open Tool on a card to launch that tool. Items marked Coming Soon are not available yet.
