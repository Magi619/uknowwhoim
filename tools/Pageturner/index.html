Order Code Extractor — How to Use

Extract order codes from PDF files, check the results and export the codes for the supported business areas.

Extract codes from PDFs

  • Select one or more PDF files using the PDF picker, or drop files into the file area.
  • Choose whether to include links in the Excel output if that option is required.
  • Select RUN — Extract & Verify to read the PDFs, extract codes and run the available checks.

Export the results

  • Use the Laithwaites, Sunday Times or Averys export option for the required output.
  • Use Clear to reset the current results and start another extraction.
