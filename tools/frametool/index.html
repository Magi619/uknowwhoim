Frame Tool — How to Use

Place a frame around an uploaded image and export the finished composition as a PNG.

Create the frame

  • Choose an image file to load it onto the canvas.
  • Select a frame colour using the colour picker or the preset colour buttons.
  • Enable Gradient to use two colours, then select Horizontal or Vertical for the gradient direction.

Download

  • Review the frame on the canvas and adjust the colours or direction as needed.
  • Select Download PNG to save the finished image.
