How to Use This Tool

Akamai Image Cache Clear Link Generator helps you create image URLs for product SKUs by market, so you can open or copy the links for cache clearing.

Getting Started

  • Select a market: Choose UK, US, or APAC to use the appropriate image URL patterns.
  • Enter SKUs: Type product codes into the “SKU Input” cells, or paste multiple SKUs from a spreadsheet into the first cell.
  • Browse Folder: Select a folder containing image files to fill the input rows with their filenames, without file extensions.
  • Generate Links: Create all image URLs for the selected market. Use the links to open images in a new tab.
  • Copy All: Copy generated URLs for every non-empty SKU to the clipboard.
  • Clear: Remove entered SKUs and generated links from the table.
  • Open Akamai: Open the Akamai Control Center in a new tab.

Useful Notes

  • For each SKU, the tool generates the image URLs associated with the selected market.
  • APAC includes Australia and New Zealand URLs, including the News24 Wine primary and alternate image links.
  • This page generates URLs only; it does not sign in to Akamai or clear caches automatically.
