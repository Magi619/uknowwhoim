Monthly AHD — How to Use

Turn an Excel or CSV report into a grouped monthly summary, with configurable row labels and count or sum fields.

Load your source file

  • Choose an Excel or CSV file. CSV files can be processed offline; Excel files use the spreadsheet reader included with the page.
  • Select the processing mode: raw data grouping or the relevant exported PivotTable format.

Map columns and process

  • Choose the row label / category column and the three fields or numeric columns to count or total.
  • For the Jira/Excel Brand layout, the defaults are AA — Labels, EZ — Custom field (Brand), FA — Custom field (Brand), and FB — Custom field (Brand).
  • Select Apply column mapping to build the summary. Use the search, copy-table and Download CSV controls on the results.
