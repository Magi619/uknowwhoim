About this Tool

This Batch Stock Lookup tool is built to simplify large-scale product checks. Paste multiple product codes at once, and the system will automatically fetch real-time stock details, validate their availability, and flag invalid or outdated codes.

Results are organized into clear categories — Valid Stock, Invalid/Remarks, Vintage Changes, and Happy to Wait.

In short: faster lookups, fewer errors, and more confidence in your stock data.

If the result shows an error/NA for an item, please double-check it with GV.

Batch Stock Lookup — How to Use

Check multiple product codes in one run, review stock quantities and vintage changes, and export the results.

Run a stock check

  • Paste product codes into the input box, one code per line.
  • Choose the required stock threshold or keep the default setting.
  • Select Fetch Stock Info to process the pasted product codes.

Review and export

  • Review the Valid Stock Quantity, Vintage Changed, Invalid / Remarks and other result sections.
  • Use the vintage filter options to review the relevant vintage results.
  • Use Clear Cache when you need to remove cached lookup data, and Export to Excel to save the results.
